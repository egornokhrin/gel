## О проекте
Цель проекта — **создать удобную площадку для представления разработчика, его работ и профессиональных интересов** (или ваша цель).

При разработке особое внимание уделено **организации компонентов, визуальной структуре страницы и адаптации интерфейса под различные размеры экрана**.

Проект также служит практическим примером применения **React и современных инструментов frontend-разработки**.

## Возможности
- **Главный экран** — представление разработчика и основных направлений деятельности.
- **Навигация** — переход между разделами сайта.
- **Услуги** — описание направлений работы.
- **Процесс разработки** — представление основных этапов выполнения задач.
- **Портфолио** — демонстрация проектов со ссылками на GitHub.
- **Статистика** — отдельный блок с показателями.
- **Контакты** — контактная секция с демонстрационной формой.
- **Адаптивная вёрстка** — настройка интерфейса для разных размеров экрана.
- **Компонентная организация** — разделение страницы на отдельные React-компоненты.

## Технологический стек
| Технология | Назначение |
|------------|------------|
| React | Создание пользовательского интерфейса на основе компонентов |
| JavaScript | Реализация логики приложения |
| HTML5 | Структура веб-страницы |
| CSS3 | Стилизация и адаптивная вёрстка |
| Vite | Запуск сервера разработки и сборка приложения |
| npm | Установка и управление зависимостями |
| Git | Контроль версий исходного кода |
| GitHub | Хранение репозитория |
| Oxlint | Проверка кода с помощью линтера |
